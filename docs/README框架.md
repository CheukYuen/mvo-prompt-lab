# 2. 产品定位

## 2.1 一句话介绍

> **智能投顾3.0** 是基于 **大模型 + 资产配置引擎** 构建的智能投顾助手，可辅助业务人员完成 **客户风险评估、市场解读、资产配置与产品推荐**。

其核心目标是：

**帮助业务人员更快、更专业地完成投资建议与客户服务。**

---

## 2.2 解决什么问题

在实际财富管理业务中，投顾人员通常面临以下问题：

### 1 投资建议依赖个人经验

不同客户经理的投资能力差异较大：

- 投资观点不统一
- 建议缺乏系统逻辑
- 难以快速形成专业方案

智能投顾3.0可以：

- 自动生成 **资产配置方案**
- 提供 **结构化投资逻辑**
- 辅助形成 **专业投资建议**

---

### 2 投顾服务效率低

传统投顾服务流程较长：

客户分析 → 市场判断 → 产品筛选 → 投资建议

通常需要：

**30分钟 — 数小时**

智能投顾3.0可以在 **几秒内生成完整建议**。

---

### 3 市场解读难度高

市场环境复杂：

- 宏观数据
- 政策变化
- 全球市场

智能投顾3.0可以：

快速生成 **市场解读报告**，帮助业务人员理解当前市场环境。 

---

### 4 产品选择困难

产品数量多：

- 基金
- 理财
- 存款
- 另类资产

业务人员难以快速筛选合适产品。

智能投顾3.0可根据：

- 客户风险等级
- 投资目标
- 市场环境

自动推荐 **适合客户的投资产品组合**。 

---

# 3. 核心能力地图

智能投顾3.0目前提供 **四类核心能力**：

---

## 3.1 市场解读

帮助业务人员快速理解当前市场环境。

系统可以自动生成：

- 宏观经济分析
- 全球市场走势
- 四大类资产观点

例如：

- 当前经济处于 **弱复苏阶段**
- 权益资产估值处于低位
- 债券配置价值上升

适用场景：

- 投顾晨会
- 客户市场沟通
- 投资观点参考

---

## 3.2 客户资产配置

根据客户信息生成 **资产配置方案**。

系统会综合：

- 客户风险等级
- 投资目标
- 生命周期阶段
- 市场环境

生成完整投资组合。

例如：

- 稳进平衡型
- 成长进取型
- 防守优化型配置方案

适用场景：

- 客户资产规划
- 投顾方案设计
- 客户投资建议

---

## 3.3 客户持仓分析

对客户当前投资组合进行 **量化诊断**。

系统可以识别：

- 资产配置偏离
- 风险暴露问题
- 组合效率问题

并给出优化建议，例如：

- 权益配置不足
- 现金比例过高
- 缺乏分散资产

适用场景：

- 老客户资产复盘
- 客户调仓建议
- 投资组合诊断

---

## 3.4 产品推荐

根据客户画像与市场环境推荐 **投资产品组合**。

系统会筛选：

- 符合风险等级
- 历史表现优良
- 策略分散合理

例如：

Top 5 推荐产品组合。 

适用场景：

- 客户产品推荐
- 投顾组合设计
- 产品销售支持

---

# 4. 快速体验路径

本章节用于帮助业务人员 **5分钟体验核心能力**。

推荐体验顺序：

```
1 市场解读
↓

2 客户资产配置

↓

3 持仓分析

↓

4 产品推荐
```

推荐原因：

市场解读 → 帮助理解当前市场
资产配置 → 生成投资组合
持仓分析 → 诊断客户账户
产品推荐 → 推荐具体产品

这是完整的 **投顾服务流程体验**。

当前版本仍处于 **产品体验阶段**：

- 部分功能仍在优化

- 主要用于 **产品体验与测试**

将其作为 **投顾辅助工具** 使用。
