# 平安银行智能投顾3.0

## 业务体验指引 README

---

# 1 产品概述

## 1.1 产品简介

**智能投顾3.0** 是基于 **大模型能力与资产配置引擎** 构建的智能投顾助手，可辅助业务人员完成 **资产配置建议、市场解读、产品推荐与持仓分析** 等投顾服务。

系统通过整合：

- 客户风险等级
- 投资目标
- 市场环境
- 资产配置模型

为客户生成 **可解释、可执行的投资建议**，帮助业务人员提升投顾服务效率与专业度。

---

## 1.2 产品目标

智能投顾3.0的核心目标包括：

- 提升投顾服务效率
- 提供科学的资产配置建议
- 辅助客户经理生成专业投资观点
- 提升客户资产配置体验

---

## 1.3 适用对象

本功能适用于以下角色：

- 客户经理
- 投资顾问
- 理财经理
- 财富管理产品经理

---

# 2 核心能力

智能投顾3.0当前提供 **四大核心能力**。


| 能力模块 | 功能说明                  |
| ---- | --------------------- |
| 资产配置 | 根据客户风险等级与投资目标生成资产配置建议 |
| 市场解读 | 自动生成宏观及市场环境分析         |
| 产品推荐 | 在资产配置基础上匹配适合的理财产品     |
| 持仓分析 | 对客户当前持仓结构进行风险收益诊断     |


---

## 2.1 资产配置

资产配置能力根据：

- 客户风险等级（C1–C5）
- 投资目标收益率
- 当前市场环境

生成 **多套差异化资产配置方案**。

资产配置逻辑参考：

- 现代投资组合理论（MPT）
- 风险平价（Risk Parity）
- 目标风险模型（Target Risk）

输出结果包括：

- 大类资产配置比例
- 目标收益率
- 风险特征说明
- 当前市场环境判断

---

## 2.2 市场解读

系统自动整合宏观经济与市场数据，生成 **市场环境解读**，帮助业务人员快速理解当前市场趋势。

解读内容包括：

- 通胀环境
- 利率环境
- 股市趋势
- 大类资产机会

---

## 2.3 产品推荐

在资产配置方案基础上：

- 匹配银行产品池
- 推荐符合风险等级的理财产品

输出包括：

- 推荐产品
- 风险等级
- 产品特征
- 推荐逻辑

---

## 2.4 持仓分析

持仓分析能力可对客户当前资产进行：

- 资产结构分析
- 风险暴露分析
- 分散度分析

并生成 **持仓优化建议**。

# 3 体验路径

当前可通过 **两种方式** 体验智能投顾3.0。

---

# 3.1 方式一：智能投顾3.0专属页面

进入路径：

**平安银行 APP → 扫描二维码 -> 智能投顾3.0 页面**

在对话界面上方可看到功能模块：

- 资产配置
- 市场解读
- 产品推荐
- 持仓分析

点击对应模块即可触发相关能力。

---

# 3.2 方式二：快捷服务（万服）对话框

在 **万服（快捷服务）对话框** 中输入问题，系统会自动进行 **意图识别** 并调用对应智能体能力。

示例：


| 输入内容   | 系统触发能力 |
| ------ | ------ |
| 专属资产配置 | 资产配置   |
| 持仓分析   | 持仓分析   |
| 市场解读   | 市场解读   |


例如输入：

```
专属资产配置
```

系统将自动触发 **资产配置能力** 并生成配置建议。

# 6 注意事项

为确保系统体验效果，请留意以下说明。

---

## 万服（快捷服务）体验说明

在 **万服（快捷服务）对话框** 中使用时，系统通过 **意图识别机制** 自动匹配对应智能体能力。

在个别复杂对话场景下，可能出现意图识别偏差，导致多轮对话中断或跳出投顾板块。

该能力正在持续优化，后续版本将进一步提升 **多轮对话稳定性与识别准确度**。

---

## 持仓分析能力说明

当前 **持仓分析功能** 在部分赎回场景下，由于缺少完整的历史赎回数据，对个别收益计算结果可能存在一定偏差。

相关能力正在持续升级，后续版本将进一步完善 **收益计算与持仓分析维度**。

---

## 白名单体验机制

智能投顾3.0涉及 **客户资产与账户相关信息**，
为确保数据安全，体验入口目前仅对 **白名单用户开放**。

如需开通体验权限，请联系项目组。

# 7 常见问题（FAQ）

---

### Q1：智能投顾3.0是否会自动交易？

不会。

系统仅提供 **资产配置建议与产品推荐**，实际投资操作需由客户或客户经理确认。

---

### Q2：生成的资产配置是否固定？

不是。

系统会根据：

- 客户风险等级
- 市场环境变化

动态生成资产配置建议。

---

### Q3：是否所有用户都可以体验？

目前仅对 **白名单用户开放体验**。
